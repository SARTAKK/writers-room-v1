# Writer's Room v1

AI skill for Claude & Gemini: turn a vague idea into a logline + 6-paragraph synopsis via a 7-writer room.

## Install
- **Claude:** copy the `writers-room-v1/` folder into your skills directory.
- **Gemini:** paste `writers-room-v1/SKILL.md` into a Gem's instructions, `GEMINI.md`, or your agent's skills/rules folder.

## What it does
Discovery, 7 locked IMDb references, 4 loglines, then a 6-paragraph 3-act synopsis refined over up to 15 internal epochs, exported as DOCX + PDF through the DOCX and PDF skills.
